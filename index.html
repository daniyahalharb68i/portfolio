Graduation Projectمشروع التخرج 2026

MobiGard — Mobile Security & Vulnerability Detectorكاشف سوء الاعدادات

My graduation project — an Android application that analyzes installed apps and detects security risks based on granted permissions. Collaborated with a team to build a cloud-based AI backend (Render) that scores each app from Safe to Critical, highlights dangerous permissions, and guides users to delete or restrict them. Features Jetpack Compose UI, cloud-stored scan history, and PDF report generation. مشروع تخرجي — تطبيق أندرويد يحلل التطبيقات المثبتة ويكشف المخاطر الأمنية بناءً على الأذونات الممنوحة. تعاونت مع فريق لبناء خادم ذكاء اصطناعي سحابي (Render) يصنف كل تطبيق من آمن إلى حرج، ويبرز الأذونات الخطرة، ويرشد المستخدمين لحذفها أو تقييدها. يتضمن واجهة Jetpack Compose وسجل فحص سحابي وإنشاء تقارير PDF.
